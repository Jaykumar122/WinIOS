# WINIOS CAMPAIGN 220 — GUEST ABI v1.4 SPECIFICATION

**Document Target:** `artifacts/campaign-220/220_abi_v1_4.md`  
**Reference Document:** `docs/abi/winios_guest_abi_v1_4.md`  
**Target Profile:** iPhone 15 (`iPhone15,4` / `D37AP` / Apple A16 Bionic `T8120`)  
**Guest Granule:** 16 KB (`TCR_EL0.TG0 = 0b10`)  
**ABI Release Version:** `0x00010400` (ABI v1.4)  

---

## Executive Summary

Campaign 220 formalizes Guest ABI Version 1.4, consolidating:
1. Pure unprivileged ARM64 EL0 userspace execution model.
2. Pinned Darwin/XNU syscall numbers from `xnu-10002.1.13 bsd/sys/syscall.h`.
3. Strict AAPCS64 register roles with Darwin error flag convention (`X16` carries syscall number on trap, returns 0 for success, 1 for error).
4. Full thread-context preservation including 32 128-bit vector registers (`V0`–`V31`) and `TPIDR_EL0`.
5. Category C ABI v1.4 extensions: thread creation, join, exit, mutex ownership tracking with `EPERM` enforcement, and IPC message traps.
6. 16 KB translation granule with ASID tagging in `TTBR0_EL1[63:48]`.

See complete technical details in `docs/abi/winios_guest_abi_v1_4.md`.
