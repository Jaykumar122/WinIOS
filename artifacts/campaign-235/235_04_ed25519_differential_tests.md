## 3. Adversarial and Malformed Encoding Defenses

### 3.1 Small-Order & Identity Point Rejections
- **Identity Public Key $(0, 1)$:** Explicitly rejected by RFC 8032 verification rules; verification returns `false`.
- **Order-2 Point $(0, p - 1)$:** Tested with $y = 2^{255} - 20$; verification rejected.
- **Degenerate R-points:** Signature with identity $R = (0, 1)$ is rejected.

### 3.2 Non-Canonical Encodings
- **Non-canonical $y$-coordinate ($y \ge p$):** Tested with $y = p$ ($2^{255} - 19$). RFC 8032 Section 5.1.3 mandates rejection; point decompression returns `false`.
- **Non-canonical scalar $S \ge L$:** Tested with $S = L$ and $S > L$. RFC 8032 Section 5.1.7 mandates $0 < S < L$; verification returns `false`.
- **Zero scalar $S = 0$:** Verification returns `false`.

### 3.3 Large Payload Integrity
- **Payload:** 64 KB pseudo-random byte stream.
- **Signing & Verification:** Verified successfully.
- **Bit Mutation:** Single bit alteration at byte offset 32768 causes immediate signature verification failure.
