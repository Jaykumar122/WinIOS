# WinIOS Campaign 225 — Stage 225.20 Guest SDK v1.9 & Category C ABI v1.9

## 1. ABI v1.9 Specification
Campaign 225 introduces **Category C ABI v1.9** (`WINIOS_CATEGORY_C_ABI_VERSION_1_9 = 0x00010900`), extending the stable guest-to-host interface with 15 hardware-abstraction syscalls ($546 - 560$).

### Architecture & Calling Convention:
- **Target:** ARM64 AArch64 Darwin Mach-O calling conventions.
- **Syscall Calling Convention:**
  - Syscall number passed in register `x16`.
  - Arguments passed in registers `x0` through `x5`.
  - Return code returned in register `x0`.
  - Triggered via `svc #0x80`.
  - Preserves standard callee-saved registers (`x19`–`x28`, `x29`, `x30`).

## 3. Guest SDK Headers & C Runtime Wrappers
- **Header Files:**
  - `include/winios_sdk/winios_sdk.h`: Canonical ABI constants and definitions.
  - `guest-sdk/include/winios/devices/device.h`: Clean public device C definitions.
  - `guest-sdk/include/winios/winios.h`: Master umbrella header.
  - `guest-sdk/include/winios/winios_types.h`: Core typedefs.
- **C Runtime Implementation:**
  - `guest-sdk/lib/winios_runtime.c`: Type-safe wrapper routines for all 15 syscalls with freestanding memory operations hardened against recursive LLVM optimizer idioms (`volatile` pointer casts).
