# WinIOS Campaign 228: Category C ABI v2.2 Syscall Reference

## 1. Specification & Header Definition

Category C ABI v2.2 allocates Syscalls 581 through 590:
- Version Identifier: `WINIOS_CATEGORY_C_ABI_VERSION_2_2 = 0x00020200`
- Syscall dispatch vector: `src/kernel/user_syscall_dispatcher.cpp`
- Public headers: `include/winios_sdk/winios_sdk.h` and `guest-sdk/include/winios/winios_types.h`

---

## 2. Syscall Directory (581..590)

| Syscall Number | Constant | Arguments | Return Value | Description |
|---|---|---|---|---|
| **581** | `SYS_WINIOS_SETTINGS_GET` | `X0`: `winios_settings_snapshot_t*` | 0 on success, -errno on error | Retrieves current system preferences snapshot |
| **582** | `SYS_WINIOS_SETTINGS_SET` | `X0`: `uint32_t key`, `X1`: `uint64_t val` | 0 on success, -errno on error | Mutates typed system setting parameter |
| **583** | `SYS_WINIOS_THEME_GET` | `X0`: `uint32_t* out_th`, `X1`: `uint32_t* out_ac` | 0 on success, -errno on error | Queries active theme mode and accent color |
| **584** | `SYS_WINIOS_THEME_SET` | `X0`: `uint32_t theme`, `X1`: `uint32_t accent` | 0 on success, -errno on error | Updates desktop theme and accent |
| **585** | `SYS_WINIOS_CONTROL_CENTER_TOGGLE` | `X0`: `uint32_t action` (0=toggle, 1=show, 2=hide, 3=query) | Current visibility (0 or 1), -errno on error | Toggles Control Center overlay |
| **586** | `SYS_WINIOS_TASK_ENUMERATE` | `X0`: `winios_task_entry_t*`, `X1`: `max_count`, `X2`: `uint32_t* out_count` | Number of tasks written, -errno on error | Lists running applications and PIDs |
| **587** | `SYS_WINIOS_TASK_SWITCH` | `X0`: `uint32_t target_pid` (0 = cycle next) | Selected PID on success, -errno on error | Changes active foreground application |
| **588** | `SYS_WINIOS_TASK_TERMINATE` | `X0`: `uint32_t target_pid`, `X1`: `uint32_t graceful` | 0 on success, -errno on error | Requests task termination |
| **589** | `SYS_WINIOS_ACCESSIBILITY_GET` | `X0`: `winios_accessibility_info_t*` | 0 on success, -errno on error | Queries active accessibility options |
| **590** | `SYS_WINIOS_ACCESSIBILITY_SET` | `X0`: `uint32_t text_scale`, `X1`: `uint32_t high_contrast` | 0 on success, -errno on error | Configures accessibility parameters |

## 3. ABI Data Structures

### 3.1 `winios_settings_snapshot_t` (48 bytes)
```c
typedef struct {
    uint32_t theme_mode;          // 0=Light, 1=Dark, 2=System
    uint32_t accent_color;        // 0=Blue..7=Graphite
    uint32_t display_width;
    uint32_t display_height;
    uint32_t display_scale;       // 100, 125, 150, 200
    uint32_t display_orientation; // 0=Landscape, 1=Portrait
    uint32_t master_volume;       // 0..100
    uint32_t is_muted;            // 0 or 1
    uint32_t low_power_mode;      // 0 or 1
    uint32_t text_scale_percent;  // 100..200
    uint32_t high_contrast;       // 0 or 1
    uint32_t network_enabled;     // 0 or 1
} winios_settings_snapshot_t;
```

### 3.2 `winios_task_entry_t` (120 bytes)
```c
typedef struct {
    uint32_t pid;
    uint32_t state;               // 0=Running, 1=Suspended, 2=Zombie, 3=Crashed
    uint32_t is_foreground;       // 0 or 1
    uint32_t pad;
    uint64_t primary_window;
    char     name[32];
    char     bundle_id[64];
} winios_task_entry_t;
```

### 3.3 `winios_accessibility_info_t` (32 bytes)
```c
typedef struct {
    uint32_t text_scale_percent;
    uint32_t high_contrast;
    uint32_t reduce_motion;
    uint32_t focus_indicator_visible;
    uint32_t screen_reader_active;
    uint32_t pad[3];
} winios_accessibility_info_t;
```
