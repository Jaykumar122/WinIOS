# Campaign 226: Category C ABI v2.0 & Guest SDK Specification

## 1. ABI v2.0 Overview
Campaign 226 formalizes Category C ABI Version 2.0 (`0x00020000`). It introduces 10 new window-system and interaction syscalls (Syscalls 561 through 570), moving WinIOS beyond device access to full interactive desktop application development.

## 2. Category C Syscall Table (Syscalls 561..570)

| Syscall Number | Syscall Name | Calling Convention / Arguments | Return Value | Description |
|:---|:---|:---|:---|:---|
| **561** | `SYS_WINIOS_WINDOW_CREATE_V2` | `X0`: title ptr<br>`X1`: x, `X2`: y<br>`X3`: width, `X4`: height<br>`X5`: flags | `X0`: 64-bit window handle (`0` on error) | Creates a desktop window owned by calling PID; returns 64-bit generation handle. |
| **562** | `SYS_WINIOS_WINDOW_DESTROY_V2`| `X0`: 64-bit window handle | `X0`: `0` (success), `-1` (errno) | Destroys window, closes surface, and purges event queue. Validates PID ownership. |
| **563** | `SYS_WINIOS_WINDOW_SET_STATE` | `X0`: 64-bit handle<br>`X1`: uint32 state | `X0`: `0` (success), `-1` (errno) | Sets window state: Normal (0), Minimized (1), Hidden (2), Closed (3), Maximized (4). |
| **564** | `SYS_WINIOS_WINDOW_GET_STATE` | `X0`: 64-bit handle<br>`X1`: uint32 out ptr | `X0`: `0` (success), `-1` (errno) | Copies current window state into user-space buffer. |
| **565** | `SYS_WINIOS_WINDOW_INVALIDATE_RECT` | `X0`: 64-bit handle<br>`X1`: rect ptr `[x, y, w, h]` | `X0`: `0` (success), `-1` (errno) | Invalidate client sub-rectangle to schedule compositor damage redraw. |
| **566** | `SYS_WINIOS_EVENT_POLL_V2` | `X0`: 64-bit handle<br>`X1`: event out ptr<br>`X2`: max_events | `X0`: Number of events popped (`0` if empty) | Non-blocking poll of bounded per-window FIFO event queue. |
| **567** | `SYS_WINIOS_EVENT_WAIT` | `X0`: 64-bit handle<br>`X1`: event out ptr<br>`X2`: timeout_ms | `X0`: Number of events popped (`0` on timeout) | Blocking wait for incoming window events with millisecond timeout. |
| **568** | `SYS_WINIOS_TEXT_INPUT_SUBMIT`| `X0`: text ptr<br>`X1`: len (bytes, max 256) | `X0`: `0` (success), `-1` (errno) | Submits text string to currently focused window's event queue. |
| **569** | `SYS_WINIOS_CLIPBOARD_GET_V2` | `X0`: out buf ptr<br>`X1`: max_len | `X0`: Length written (`-1` on error) | Reads global desktop clipboard text into user buffer. |
| **570** | `SYS_WINIOS_CLIPBOARD_SET_V2` | `X0`: in buf ptr<br>`X1`: len | `X0`: Length written (`-1` on error) | Sets global desktop clipboard text from user buffer. |

## 3. Desktop Event Structure (`winios_desktop_event_t`)
The ABI specifies a 128-byte aligned event layout:
```c
typedef struct {
    uint32_t version;       /* ABI version (0x00020000) */
    uint32_t size;          /* sizeof(winios_desktop_event_t) = 128 */
    uint32_t event_type;    /* DesktopEventType enum */
    uint32_t flags;         /* Event modifier flags */
    uint64_t timestamp_us;  /* Monotonic microsecond timestamp */
    uint64_t window_handle; /* Target window 64-bit generation handle */
    union {
        struct {
            int32_t x;
            int32_t y;
            uint32_t buttons;
            int32_t wheel_delta;
        } pointer;
        struct {
            uint32_t key_code;
            uint32_t modifiers;
            uint32_t is_repeat;
        } key;
        struct {
            char text[64];
            uint32_t length;
        } text_input;
        struct {
            int32_t new_x;
            int32_t new_y;
            int32_t new_width;
            int32_t new_height;
            uint32_t old_state;
            uint32_t new_state;
        } state_change;
        uint8_t raw_payload[96];
    };
} winios_desktop_event_t;
```

## 4. Guest SDK Public Headers
The Guest SDK exports these interfaces in:
- `guest-sdk/include/winios/window/window.h`: Window lifecycle and state functions.
- `guest-sdk/include/winios/window/events.h`: Event queue, type definitions, and polling functions.
- `guest-sdk/include/winios/winios.h`: Umbrella include header.
- `guest-sdk/lib/winios_runtime.c`: C runtime assembly wrappers implementing Darwin ARM64 `svc 0x80` dispatch with `cerror` carry-flag handling.
