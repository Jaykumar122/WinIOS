# WinIOS Campaign 224 — Stage 224.21 Guest SDK v1.8 & Platform API Specification

## 1. Versioning Contract
- **SDK Version:** `0x00010800` (`v1.8.0`)
- **ABI Version:** Category C ABI v1.8 (`0x00010800`)
- **Backward Compatibility:** All existing SDK v1.5, v1.6, and v1.7 applications (Calculator, Notes v2, Resource Browser) execute unchanged.

---

## 2. Category C ABI v1.8 Syscall Registry
| Syscall Number | Constant | Description / Calling Convention |
| :---: | :--- | :--- |
| `537` | `SYS_WINIOS_CONFIG_GET` | `x0 = ptr to winios_config_req_t` |
| `538` | `SYS_WINIOS_CONFIG_SET` | `x0 = ptr to winios_config_req_t` |
| `539` | `SYS_WINIOS_LOG_LEVELED` | `x0 = level, x1 = ptr, x2 = len` |
| `540` | `SYS_WINIOS_DIAG_SUMMARY` | `x0 = ptr to winios_diag_summary_t` |
| `541` | `SYS_WINIOS_IPC_PORT_CREATE_V2` | `x0 = ptr to port name string (or 0)` |
| `542` | `SYS_WINIOS_IPC_SEND_V2` | `x0 = ptr to winios_ipc_msg_v2_t` |
| `543` | `SYS_WINIOS_IPC_RECV_V2` | `x0 = port_handle, x1 = buf, x2 = max_len, x3 = ptr out_desc` |
| `544` | `SYS_WINIOS_IPC_LOOKUP_PORT` | `x0 = ptr to name string` |
| `545` | `SYS_WINIOS_IPC_REGISTER_PORT` | `x0 = port_handle, x1 = ptr to name string` |

---

## 3. Public C Platform Interfaces
- **Configuration API:**
  - `winios_config_get_string`, `winios_config_set_string`
  - `winios_config_get_int`, `winios_config_set_int`
  - `winios_config_get_double`, `winios_config_set_double`
  - `winios_config_get_bool`, `winios_config_set_bool`
- **IPC v2 Generation API:**
  - `winios_ipc_port_create_v2`, `winios_ipc_send_v2`, `winios_ipc_recv_v2`
  - `winios_ipc_lookup_port`, `winios_ipc_register_port`
- **Platform Diagnostics API:**
  - `winios_diagnostics_get_summary(winios_platform_diagnostics_t* out_summary)`
