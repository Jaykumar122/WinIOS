# WinIOS Campaign 227: Category C ABI v2.1 Specification

## 1. Overview

Campaign 227 introduces Category C ABI v2.1, extending the WinIOS Darwin-inspired EL0 guest syscall interface with Syscalls 571 through 580 for Document Services, File Picker interaction, Stream I/O, and Access Grants.

All syscalls are dispatched via ARM64 `svc #0x80` with the syscall number in `x16`, arguments in `x0..x5`, and return values returned in `x0` (and `x1` where applicable). Negative values represent negated Darwin errno codes (e.g., `-5` = `-EIO`, `-13` = `-EACCES`).

---

| `SYS_WINIOS_DOC_SAVE_PICKER` | 572 | `winios_doc_save_picker` | `x0` = caller_win, `x1` = default_name, `x2` = filter_ext, `x3` = out_req_id | `0` = OK, `<0` = error |

| `SYS_WINIOS_DOC_STREAM_OPEN` | 574 | `winios_doc_stream_open` | `x0` = doc_handle, `x1` = mode, `x2` = out_stream_h | `0` = OK, `<0` = error |

## 3. ABI Data Structures & Memory Layouts

All structures are explicitly aligned and padded for 64-bit ARM64 architecture:

### 3.1 `winios_doc_metadata_t` (264 bytes)
```c
typedef struct {
    uint64_t doc_handle;         // Offset 0 (8 bytes)
    char     display_name[64];   // Offset 8 (64 bytes)
    char     canonical_path[128];// Offset 72 (128 bytes)
    char     mime_type[32];      // Offset 200 (32 bytes)
    uint64_t file_size;          // Offset 232 (8 bytes)
    uint64_t modified_time_us;   // Offset 240 (8 bytes)
    uint32_t owner_pid;          // Offset 248 (4 bytes)
    uint32_t is_read_only;       // Offset 252 (4 bytes)
    uint64_t reserved;           // Offset 256 (8 bytes)
} winios_doc_metadata_t;
```

### 3.2 `winios_doc_stream_info_t` (40 bytes)
```c
typedef struct {
    uint64_t stream_handle;      // Offset 0 (8 bytes)
    uint64_t doc_handle;         // Offset 8 (8 bytes)
    uint32_t mode;               // Offset 16 (4 bytes)
    uint32_t is_dirty;           // Offset 20 (4 bytes)
    uint64_t cursor;             // Offset 24 (8 bytes)
    uint64_t buffer_size;        // Offset 32 (8 bytes)
} winios_doc_stream_info_t;
```

### 3.3 `winios_doc_grant_req_t` (32 bytes)
```c
typedef struct {
    uint64_t doc_handle;         // Offset 0 (8 bytes)
    uint32_t grantee_pid;        // Offset 8 (4 bytes)
    uint32_t mode;               // Offset 12 (4 bytes)
    uint64_t expiry_us;          // Offset 16 (8 bytes)
    uint64_t out_grant_token;    // Offset 24 (8 bytes)
} winios_doc_grant_req_t;
```

### 3.4 `winios_recent_doc_t` (208 bytes)
```c
typedef struct {
    uint64_t doc_handle;         // Offset 0 (8 bytes)
    char     display_name[64];   // Offset 8 (64 bytes)
    char     canonical_path[128];// Offset 72 (128 bytes)
    uint64_t last_opened_time_us;// Offset 200 (8 bytes)
} winios_recent_doc_t;
```
