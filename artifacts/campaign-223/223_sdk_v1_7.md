# WinIOS Campaign 223 — Guest SDK v1.7 Specification (Stage 223.17)

## 1. Executive Summary

Campaign 223 increments the Guest SDK to **v1.7** (`WINIOS_SDK_VERSION 0x00010700`, Category C ABI v1.7). The SDK introduces high-level application orchestration (`winios_app_t`), flexbox layout computation (`winios_layout_node_t`), and interactive UI components (`textarea`, `slider`, `dialog`, `menu`, `focus`).

---

## 2. Header Architecture & Invariants

```
guest-sdk/include/winios/
├── winios.h                 # Master SDK include
├── winios_types.h           # Core types, error codes, version constants (v1.7)
├── app/
│   └── app.h                # winios_app_t, lifecycle callbacks & config
├── ui/
│   ├── event.h              # Event V2 definitions & key codes
│   ├── font8x8.h            # 8x8 bitmap glyph matrix
│   ├── graphics.h           # Drawing primitives & color utilities
│   ├── layout.h             # Flex layout tree (Row, Column, Absolute)
│   ├── toolkit.h            # Button, label, textarea, slider, dialog, menu
│   └── window.h             # Window and surface descriptors
├── system/
│   ├── process.h            # Process spawning, exit, yield
│   └── syscall.h            # Category C syscall wrappers (svc #0x80)
├── storage/
│   ├── storage.h            # Persistent isolated key-value storage
│   └── vfs.h                # File descriptor & VFS operations
├── ipc/
│   └── ipc.h                # Mach-inspired message passing
├── logging/
│   └── log.h                # System log categories and levels
└── runtime/
    └── runtime.h            # App argument block & freestanding CRT
```

---

## 3. ABI Invariants & Compatibility

1. **Category C ABI v1.7**: Guaranteed backwards compatible with v1.6, v1.5, and v1.2 applications.
2. **Freestanding CRT**: Zero dependence on macOS Libsystem or external glibc/MSVCRT.
3. **Deterministic Memory Footprint**: Layout and UI controls operate entirely on caller-provided stack/static memory with zero heap requirements.
