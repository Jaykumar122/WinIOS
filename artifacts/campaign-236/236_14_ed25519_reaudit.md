## 2. Mathematical & Algorithmic Conformance

The implementation operates over the prime field $\mathbb{F}_p$ with $p = 2^{255} - 19$ on the twisted Edwards curve:
$$-x^2 + y^2 = 1 + d x^2 y^2$$
where $d = -121665 / 121666 \pmod p$.

### 1. Constant-Time Scalar Multiplication (Montgomery Ladder)
- **Ladder Invariant:** Scalar multiplication $Q = [s]P$ executes exactly **255 iterations**, processing each bit of the scalar $s$ from bit 254 down to bit 0.
- **Conditional Swap (`cswap`):** Point coordinate swaps between ladder registers $R_0$ and $R_1$ are performed using data-independent arithmetic masking:
  ```cpp
  uint64_t mask = static_cast<uint64_t>(-static_cast<int64_t>(b));
  for (size_t i = 0; i < 4; ++i) {
      uint64_t delta = mask & (p->x[i] ^ q->x[i]);
      p->x[i] ^= delta;
      q->x[i] ^= delta;
  }
  ```
- **Zero Secret-Dependent Branching:** The scalar bit $b \in \{0, 1\}$ is never used in an `if`, `while`, or ternary operator.
- **Zero Secret-Dependent Memory Access:** All array lookups access identical indices on every iteration, eliminating cache-timing side channels.

### 2. Secret Memory Lifetime & Zeroization
All ephemeral private keys, expanded SHA-512 digests, and scalar representations are wiped using `SecureZeroMemory`, preventing compiler dead-store elimination.
