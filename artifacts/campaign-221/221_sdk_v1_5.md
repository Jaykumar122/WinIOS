# WinIOS Guest SDK v1.5 Architecture Report

**Campaign:** 221 (Stage 221.3)  
**SDK Version:** 1.5.0 (`0x00010500`)  
**Target Architecture:** ARM64 (AArch64 EL0)  
**Host Environment:** Windows 11 x64  
**Cross Compiler:** Zig 0.17.0 (`zig cc -target aarch64-macos -nostdlib`)  

---

## 1. SDK Layout & Component Organization

The Guest SDK v1.5 is organized as a clean, freestanding C SDK that can be directly included by any ARM64 C/C++ guest project without pulling in Windows-specific headers or host C++ runtime dependencies:

```
WinIOS/guest-sdk/
├── include/
│   └── winios/
│       ├── winios.h             (Umbrella header)
│       ├── winios_types.h       (Fixed-width integers, status codes, alignment macros)
│       ├── runtime/
│       │   └── runtime.h        (Startup contract, argument/env accessors, exit)
│       ├── system/
│       │   ├── syscall.h        (Inline AArch64 assembly syscall wrappers for svc #0x80)
│       │   └── process.h        (Process spawn, waitpid, process status query)
│       ├── storage/
│       │   ├── vfs.h            (Standard POSIX/BSD VFS open/read/write/close/pipe)
│       │   └── storage.h        (Isolated per-application persistent storage)
│       ├── ui/
│       │   ├── window.h         (Window creation, destruction, title, geometry, focus)
│       │   ├── event.h          (Event polling, wait, timer creation)
│       │   └── graphics.h       (Surface fill, pixel update, display present)
│       ├── ipc/
│       │   └── ipc.h            (Mach-inspired message ports and payloads)
│       └── logging/
│           └── log.h            (Structured guest diagnostic logging)
├── lib/
│   ├── crt0.s                   (Freestanding ARM64 startup entry vector)
│   └── winios_runtime.c         (Freestanding C runtime: memory, string, formatting)
├── examples/
│   ├── runtime_explorer/
│   ├── notes/
│   └── process_monitor/
└── tools/
    └── wios_packager.py         (Windows-hosted build and packaging CLI)
```

---

## 2. ABI Categories & Calling Conventions

- **Category A (Darwin/BSD Syscalls):** Numbers 1..499. Syscall number in `X16`, arguments in `X0`..`X5`. Invoked via `svc #0x80`.
- **Category B (Mach Message Traps):** Number `0x80000001` (`kSysWiniosMsgTrap`).
- **Category C (WinIOS Accelerated Subsystems):** Numbers 500..526. Extended desktop, window, isolated storage, event, and logging services.

---

## 3. Strict Decoupling from Host Runtime

1. **No `<windows.h>`:** All types are derived from standard `<stdint.h>` and `<stddef.h>`.
2. **Explicit Packing:** Structures crossing the guest-to-kernel boundary are explicitly packed `#pragma pack(push, 8)` with verified `static_assert` sizes.
3. **No Dynamic Host Linking:** All guest binaries are freestanding Mach-O images cross-compiled with Zig.
