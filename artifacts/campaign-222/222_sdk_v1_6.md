# WinIOS Campaign 222 — Stage 222.19: Developer SDK v1.6 & Packaging Tooling Evolution Report

## 1. Executive Summary

Stage 222.19 evolves the WinIOS Developer SDK from v1.5 to v1.6 (`WINIOS_SDK_VERSION 0x00010600`) and updates the guest packaging tooling (`guest-sdk/tools/wios_packager.py` and `tools/wpack.py`).

The v1.6 SDK establishes the developer interface for building interactive ARM64 guest applications featuring multi-window capabilities, 2D UI widgets (buttons, labels, text input, checkboxes, progress bars), window visibility controls, clipboard integration, and application supervisor state notifications.

---

## 2. ABI & SDK Version Bumps

The Category C ABI and SDK definitions were updated across:
- `guest-sdk/include/winios/winios.h`: Public umbrella header updated for SDK v1.6.
- `guest-sdk/include/winios/winios_types.h`: `WINIOS_SDK_VERSION_MAJOR` (1), `WINIOS_SDK_VERSION_MINOR` (6), `WINIOS_SDK_VERSION` (`0x00010600`).
- `include/winios_sdk/winios_sdk.h`: ABI and SDK version macros bumped to `0x00010600`.
- Category C Syscalls 530..536 documented and exposed:
  - `530`: `SYS_WINIOS_WINDOW_GET_PROPERTIES`
  - `531`: `SYS_WINIOS_WINDOW_SET_GEOMETRY_V2`
  - `532`: `SYS_WINIOS_WINDOW_RAISE`
  - `533`: `SYS_WINIOS_WINDOW_SET_VISIBILITY`
  - `534`: `SYS_WINIOS_CLIPBOARD_GET`
  - `535`: `SYS_WINIOS_CLIPBOARD_SET`
  - `536`: `SYS_WINIOS_APP_SUPERVISOR_NOTIFY`

---

## 3. UI Toolkit Header & Freestanding Runtime Exports

The Guest SDK v1.6 introduces:
- `guest-sdk/include/winios/ui/toolkit.h`: Defines structures and functions for interactive widgets:
  - `winios_button_t`, `winios_button_init`, `winios_button_draw`, `winios_button_handle_event`
  - `winios_label_t`, `winios_label_init`, `winios_label_draw`
  - `winios_textinput_t`, `winios_textinput_init`, `winios_textinput_draw`, `winios_textinput_handle_event`
  - `winios_checkbox_t`, `winios_checkbox_init`, `winios_checkbox_draw`, `winios_checkbox_handle_event`
  - `winios_progressbar_t`, `winios_progressbar_init`, `winios_progressbar_draw`
- `guest-sdk/include/winios/ui/font8x8.h`: Embedded 8x8 bitmap font glyphs (ASCII 32 to 126).
- `guest-sdk/lib/winios_runtime.c`: Freestanding C implementations linking directly against Zig compiler output without libc runtime dependencies.

---

## 4. Packaging Tooling Evolution

`wios_packager.py` and `wpack.py` now support:
- `min_os_version=222.0`
- `min_abi_version=1.6`
- Extended permissions: `display.window,storage.private,logging,clipboard,ipc`
- Strict path traversal filtering and SHA-256 binary validation within container creation.

All tools and SDK headers have been validated against the MSVC C++20 `/W4 /WX /permissive-` compilation policy.
