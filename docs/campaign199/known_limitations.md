# WinIOS Campaign 199: Known Limitations & Research Boundaries

**Target Research Device Profile:** iPhone 15 (`iPhone15,4` / `D37AP` / Apple A16 Bionic `T8120`)  
**Scope:** Virtual Platform, Stage-2 MMU, IOMMU, PAC & Device Architecture  

---

## 1. Bounded Pointer Authentication Cryptography
- **Limitation:** In the hardware implementation of Apple A16 Bionic, Pointer Authentication Codes are generated by dedicated cryptographic hardware pipelines executing a proprietary variant of QARMA-64 with silicon-fused secret seeds.
- **Emulator Behavior:** WinIOS implements a bounded, deterministic cryptographic permutation across the 128-bit key, pointer, and modifier. While all architectural properties (signature bit locations, modifier sensitivity, error bit 62 flipping on failure, synchronous `EC = 0x1C` exception delivery, and system register privilege gates) are exact, the raw bit values of the 16-bit signature differ from silicon hardware.
- **Classification:** `ARM64E_PAC_BOUNDED`.

---

## 2. Virtual IOMMU Page Sizing & Table Structures
- **Limitation:** `VirtualIommu` models Apple DART using a memory-resident radix-tree and fast hash cache supporting 16KB and 4KB pages.
- **Emulator Behavior:** Non-power-of-two page sizes or sub-page windowing are not supported, which conforms to standard hardware specifications. Direct hardware register-level DART table walker state machines are simulated architecturally rather than cycle-accurate hardware logic.
- **Classification:** `VIRTUAL_IOMMU`.

---

## 3. Stage-2 Block Paging Limits
- **Limitation:** The 16KB translation granule engine supports Level 2 (32MB block) and Level 3 (16KB page) descriptors over a 48-bit IPA space (`T0SZ = 16`).
- **Emulator Behavior:** Level 1 gigabyte block concatenation is not implemented, as the current virtual platform address space is constrained to 4GB physical RAM.
- **Classification:** `STAGE2_TRANSLATION`.

---

## 4. GICv3 vs Apple AIC Architecture
- **Limitation:** For generic hypervisor and Linux guest testing, WinIOS exposes a standard ARM GICv3 interrupt controller with distributor, redistributors, and EL2 virtualization list registers.
- **Emulator Behavior:** Genuine iPhone 15 hardware utilizes the proprietary Apple Interrupt Controller (AIC). While WinIOS includes an AIC emulator for Darwin execution, the Stage-2 / EL2 virtualization test harnesses utilize GICv3 list registers (`ICH_LR_EL2`) for standards-compliant hypervisor verification.
- **Classification:** `VIRTUAL_GIC` / `APPLE_AIC`.

---

## 5. Proprietary Secure Silicon Coprocessors
- **Limitation:** Hardware subsystems including the Secure Enclave Processor (SEP), Apple Neural Engine (ANE), and Always-On Processor (AOP) are represented via architectural memory and MMIO bounds.
- **Emulator Behavior:** WinIOS does not execute genuine proprietary SEP firmware binaries, nor does it claim genuine iOS jailbreak or production boot capability. All kernel execution is performed against synthetic XNU/Darwin contracts.
- **Classification:** `SYNTHETIC_KERNEL` / `NON_GENUINE_FIRMWARE`.
